# LANDING PAGE KR

Página de presentación de **KR**, el equipo de Joselin y Jordi Daniel Reyes Hernandez. Presenta servicios para negocios con lenguaje sencillo, contacto directo y nueve ejemplos interactivos en páginas independientes.

## Abrir el sitio

Abre `inicio.html` en tu navegador. `index.html` contiene la misma presentación y funciona como entrada principal para un alojamiento web.

También puedes iniciar un servidor local desde esta carpeta:

```sh
python -m http.server 5500 --bind 127.0.0.1
```

Después abre `http://127.0.0.1:5500/inicio.html`.

## Ejemplos incluidos

- **Café Miga Pedidos:** tienda de comida para recoger, pedir a domicilio o comer en el local, con pago simulado, borrador de WhatsApp y vista del negocio.
- **Casa Laurel:** pedidos desde la mesa y entre meseros y cocina, con seguimiento de cada comanda.
- **Cortes por turnos:** efectivo esperado, faltantes o sobrantes e historial descargable.

- **Café Miga Sucursales:** página de cafetería con horarios, menú, filtros y pedido para recoger de muestra.
- **Plásticos Punto:** catálogo, precios por volumen y cotización descargable.

- **Ferre Norte:** inventario de ferretería, entradas y salidas, bitácora y reportes.
- **Forma:** tienda de ropa, tallas, colores, bolsa de compra y pedido simulado.
- **Café Miga:** conteo de billetes y monedas, diferencias y cierre de caja.
- **Estudio Oliva:** servicios, horarios, reservas de prueba y cancelaciones.

Los negocios, productos e importes son ficticios. Las demostraciones conservan sus cambios en el navegador y no realizan cobros, envíos ni reservas reales.

## Archivos

```text
inicio.html / index.html   Presentación de KR
kr-estudio.css            Diseño adaptable
kr-estudio.js             Menú, filtros y contacto
examples/                 Páginas completas de los negocios
assets/                   Tipografías locales, licencias, dibujo de portada y símbolo KR
LEEME.txt                 Instrucciones y detalles del proyecto
```

No requiere instalar paquetes ni configurar una base de datos. La presentación no incluye fotografías ni enlaces a proyectos de programación.
